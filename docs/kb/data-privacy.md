# Data and privacy

CrewGuard stores as little as it can. This note is sample policy for the demo, not legal advice.

## What is saved

- Messages the bot removes, plus the reason, so a manager can review them.
- Notes a general manager posts, which can later become help docs.
- The record that you pressed I Agree: Discord account, rules version, and time.

Normal chat is not stored.

## How long

Removed-message text and manager notes are deleted after 30 days. The agree-record stays while you are a member, because it is the proof of what you were shown. The retention timer does not delete it.

## Asking for deletion

Anyone can ask for their stored rows to be deleted. A server admin runs `crewguard forget` with that person's Discord user id. Asking does not affect your job. This bot is not the employer's system of record.
